### 🛡️ Protección Civil — Sistema de Gestión Operativa Integral
A full-stack, real-time Progressive Web App (PWA) designed to manage emergency interventions, volunteer shifts, fleet resources, and geolocation tracking for civil protection units.

- **Stack**: React 19, Vite, Node.js, Express, PostgreSQL, WebSockets
- **Highlights**: Real-time GPS volunteer tracking, SOS panic button, RBAC architecture, Push Notifications, interactive map with Leaflet.
