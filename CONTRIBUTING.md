# Contributing to Protección Civil Showcase

Thank you for your interest in the Protección Civil management system!

## Showcase Repository

Please note that this is a **showcase repository**. The actual source code for Protección Civil is proprietary and closed-source. This repository exists solely to share architectural decisions, technical design, documentation, and the stack used in the production application.

## Pull Requests

Since there is no executable source code in this repository, **we do not accept Pull Requests** for feature implementations or backend/frontend code changes.

If you spot a typo in the documentation or have suggestions on how to improve the README, diagrams, or technical documentation, feel free to open an Issue or a Pull Request!

## Security Vulnerabilities

Please **do NOT** open a public GitHub issue for security vulnerabilities. Refer to our [Security Policy](SECURITY.md) for instructions on how to responsibly disclose security issues.
